# Demo de adopción de mascotas

Este repositorio contiene un proyecto académico y demostrativo desarrollado para la asignatura **Procesos en Ingeniería del Software**.

Su objetivo es construir progresivamente una aplicación web funcional de adopción de perros y gatos mientras se aplican y documentan prácticas profesionales de ingeniería del software, desde la definición del backlog y la trazabilidad de requisitos hasta la implementación, las pruebas y las entregas. La descripción funcional y el resto de la documentación del proyecto están disponibles en [`docs`](docs/README.md).
